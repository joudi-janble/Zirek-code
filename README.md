## What it does

Zîrek code is a desktop AI workspace that reads your project, plans the work, executes real tools, verifies the result and hands you the complete conversation to keep. It connects to any API and any model, and it is built to work without topic restrictions across technical domains.

## Core capabilities

| | Capability | What it gives you |
|---|---|---|
| 💬 | **Conversational collaborator** | Ask in natural language; answers stay grounded in your actual project. |
| 🧠 | **Project-aware context** | Indexes files, symbols and dependencies for real understanding. |
| 📋 | **Multi-step planning** | Turns a request into a visible plan and executes it step by step. |
| 🛠️ | **Real tool execution** | Creates and edits files, searches code, runs commands and inspects results. |
| ✅ | **Automatic verification** | Builds and tests after changes; uses real diagnostics before claiming success. |
| ↩️ | **Review and undo** | Every change is reviewable, with one-click undo of a whole turn. |
| 🔌 | **Any API, any model** | Connect local or cloud OpenAI-compatible endpoints and custom providers. |
| 🔓 | **Unrestricted interaction** | **Primary advantage:** bypasses restrictions and filters in any AI model, including cloud models. |
| ⬇️ | **Download conversation** | Export the full chat history to keep, share or archive it. |
| 📁 | **Flexible folders** | Works with a project folder or with no folder at all. |
| 💻 | **Editor and terminal** | Multi-tab editor with syntax highlighting, plus a live integrated terminal. |
| ⚙️ | **Command palette** | Fast access to actions with customizable shortcuts. |
| 🖼️ | **Attachments and images** | Include files and pictures for analysis when the model supports vision. |
| 🧩 | **Durable memory** | Remembers decisions and outcomes across turns and sessions. |

## Fields of work

- 🛡️ **Cybersecurity** — offensive and defensive security work in one workspace.
- 🎯 **Penetration testing** — plan, execute and verify assessments without topic walls.
- 🤖 **Robotics** — experiment with autonomous systems and control logic.
- 🛩️ **Drones** — develop and test flight and payload workflows.
- 💻 **Software engineering** — explore, edit, build and verify real codebases.
- 🔬 **Research** — open-ended technical investigation with a tool-using assistant.
- 🌐 **Any field — without restrictions** — no imposed limits, no subject gates.

## Why it is different

Zîrek code is not a chat wrapper. It is a working environment: the assistant sees the project, takes actions, checks its own work using real build and test output, and lets you keep the entire conversation as an artifact. Model choice stays yours — local or cloud, any compatible API — and no topic restriction stands between you and the work.
